Firecell Core {{ .Chart.Version }} (app {{ .Chart.AppVersion }})

Release {{ .Release.Name }} in namespace {{ .Values.global.namespace }}.

Standalone 3GPP 5G Core Network with built-in atomic lifecycle:
  - Pre-flight validation hook: validates host interfaces, kernel SCTP, storage, and cluster resources.
  - Post-flight verification hook: validates MySQL schema, NF readiness, SCTP NGAP (38412), GTP-U (2152), and datapath.
  - Automatic rollback on install or upgrade failure (--atomic).

{{- if .Values.namespace.create }}

The chart creates Namespace {{ .Values.global.namespace }}. Set
namespace.create=false when something else already owns it.
{{- else }}

The chart does not create the namespace. Create it first, or pass
--create-namespace.
{{- end }}

Ensure Secret dockerhub-regcred (or your configured imagePullSecrets) is pre-created
in namespace {{ .Values.global.namespace }} before installation.

{{- if and .Values.ims.enabled (eq (.Values.ims.engine | default "kamailio") "asterisk") }}

IMS engine: asterisk. For Kamailio + Cx-on-UDR (chart default), omit examples/values-ims-asterisk.yaml.
{{- else if .Values.ims.enabled }}

IMS engine: kamailio (default) — P/I/S-CSCF + Cx. CX_SOT={{ .Values.ims.cxGateway.cxSot | default "udr" }}.
Ensure hostNetwork IPs (.205–.208) and kamailio-ims / ims-cx-gateway images are available.
Asterisk-only: layer examples/values-ims-asterisk.yaml.
{{- end }}

{{- if include "firecell-5gc.ipv6UserPlane" . }}

IPv6 user plane: on (a DNN in coreConfig.dnns has an IPv6 pool).
  - The SMF and every UPF that serves an IPv6 DNN run the CP relay (RS/RA over
    N4-u, UDP {{ include "firecell-5gc.smfN4uPort" . }}); N4 and N3 use different addresses.
{{- if not (include "firecell-5gc.smfN4uStable" .) }}
  - WARNING: the SMF N4-u address is the SMF pod IP, which changes when the pod
    is replaced. Sessions the UPF keeps across an SMF restart then send the
    UE's Router/Neighbor Solicitations to the old address (the UE keeps its
    prefix and data flows; RS/NS go unanswered until the session is
    re-established). Give the SMF a stable N4 address: smf.multus.enabled with
    smf.n4IP, or smf.hostNetwork with smf.hostPfcpIP.
{{- end }}
{{- end }}
